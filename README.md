# ระบบแจ้งผลงานนักเรียน

ระบบรับแจ้งผลงานนักเรียน (ได้รับรางวัล หรือไปแข่งขันรายการใดก็ตาม) พร้อมแนบรูปเกียรติบัตร ครูตรวจก่อนประกาศ แล้วฝ่ายประชาสัมพันธ์ทำกราฟิกแสดงความยินดีและแคปชันสำหรับเพจ Facebook และกลุ่ม LINE

- **หน้าเว็บ** อยู่บน GitHub Pages (ฟรี)
- **ข้อมูลและรูปภาพ** เก็บใน Google Drive ของโรงเรียน (Google Sheets + โฟลเดอร์รูป) ผ่าน Google Apps Script

```
ผู้ปกครอง / ครู ──► index.html (แบบฟอร์ม + แนบรูป)
                          │
                          ▼
                Google Apps Script (Code.gs)
                 ├─ ชีต "ข้อมูลผลงานนักเรียน"
                 └─ โฟลเดอร์ "รูปผลงานนักเรียน", "กราฟิกประกาศ"
                          ▲
ครูผู้ตรวจ / ประชาสัมพันธ์ ──► staff.html (เข้าด้วยรหัสเจ้าหน้าที่)
   ภาพรวม · รอตรวจ · ทำกราฟิก · ตั้งค่าโรงเรียน
```

## ขั้นตอนการทำงาน

1. **แจ้งผลงาน:** ผู้ปกครองหรือครูกรอก `index.html` แนบรูปได้สูงสุด 6 รูป แล้วได้รหัสอ้างอิง เช่น `R261111-7KQ2`
2. **ตรวจ:** ครูผู้ตรวจเปิด `staff.html` แท็บ "รอตรวจ" เทียบข้อมูลกับรูปเกียรติบัตร แล้วกด **ผ่านการตรวจ** หรือ **ส่งกลับแก้ไข**
3. **ทำกราฟิก:** ฝ่ายประชาสัมพันธ์เปิดแท็บ "ทำกราฟิก"
   - เลือกแบบและขนาดกราฟิก แล้วดาวน์โหลดภาพ PNG หรือเก็บลง Google Drive
   - คัดลอกแคปชันไปโพสต์เพจ Facebook และส่งกลุ่ม LINE
4. **บันทึกการประกาศ:** กด **บันทึกว่าประกาศแล้ว** ระบบจะเก็บว่าใครประกาศ เมื่อไร และช่องทางไหน
5. **สรุปผลงาน:** แท็บ "ภาพรวม" สรุปรายปีการศึกษา และส่งออก CSV ไปทำ SAR หรือรายงานได้

## ติดตั้ง (ใช้เวลาประมาณ 15 นาที)

### ขั้นที่ 1 · ติดตั้งระบบหลังบ้านใน Google Drive ของโรงเรียน

1. ลงชื่อเข้าใช้ด้วย **บัญชี Google ของโรงเรียน** ที่จะเป็นเจ้าของข้อมูล แล้วเปิด <https://script.google.com>
2. กด **New project** แล้วตั้งชื่อโปรเจกต์ เช่น `ระบบแจ้งผลงานนักเรียน`
3. ลบโค้ดตัวอย่างในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) ลงไปแทน
4. แก้บรรทัดบนสุดเป็นรหัสเจ้าหน้าที่ของโรงเรียน (อย่างน้อย 6 ตัวอักษร) แล้วกด 💾 Save
   ```js
   const STAFF_PASSCODE = 'ใส่รหัสของโรงเรียน';
   ```
5. ที่แถบด้านบน เลือกฟังก์ชัน **setup** แล้วกด **Run**
6. Google จะขอสิทธิ์: กด **Review permissions** แล้วเลือกบัญชีโรงเรียน
   - ถ้าขึ้นว่า *Google hasn't verified this app* ให้กด **Advanced** แล้วกด **Go to … (unsafe)** จากนั้นกด **Allow**
   - คำเตือนนี้ขึ้นเพราะเป็นสคริปต์ที่โรงเรียนเขียนใช้เอง ไม่ได้ส่งให้ Google ตรวจ
7. ดูที่ **Execution log** จะมีลิงก์โฟลเดอร์ "ระบบแจ้งผลงานนักเรียน" และชีต "ข้อมูลผลงานนักเรียน" ใน Drive

### ขั้นที่ 2 · เปิดใช้เป็นเว็บแอป

1. กด **Deploy** แล้วเลือก **New deployment**
2. กดไอคอน ⚙ ข้าง *Select type* แล้วเลือก **Web app**
3. ตั้งค่าดังนี้
   - **Execute as:** `Me` (บัญชีโรงเรียน)
   - **Who has access:** `Anyone`
4. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> **ตรวจว่าใช้ได้:** เปิด Web app URL ในเบราว์เซอร์ ต้องเห็น `{"ok":true,"app":"student-achievements","ready":true}`

### ขั้นที่ 3 · ขึ้นเว็บบน GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `student-achievements` ตั้งเป็น **Public** (GitHub Pages แบบฟรีต้องเป็น Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository
3. แก้ไฟล์ `config.js` ใส่ Web app URL จากขั้นที่ 2
   ```js
   window.APP_CONFIG = {
     API_URL: 'https://script.google.com/macros/s/AKfy.../exec'
   };
   ```
4. ไปที่ **Settings › Pages** แล้วตั้งค่า
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / `(root)`
   - กด **Save**
5. รอ 1–2 นาที จะได้ลิงก์เว็บ
   - **แบบฟอร์มแจ้งผลงาน:** `https://<ชื่อบัญชี>.github.io/student-achievements/`
   - **หลังบ้าน:** `https://<ชื่อบัญชี>.github.io/student-achievements/staff.html`

### ขั้นที่ 4 · ตั้งค่าโรงเรียน

1. เปิด `staff.html` แล้วใส่ชื่อของคุณและรหัสเจ้าหน้าที่
2. ที่แท็บ **ตั้งค่าโรงเรียน** ใส่ข้อมูลต่อไปนี้ แล้วกดบันทึก
   - ชื่อโรงเรียน, สังกัด, ตราโรงเรียน
   - สีกราฟิก, แฮชแท็ก, ลิงก์เพจ Facebook
   - **อีเมลรับแจ้งเตือน:** ครูจะได้อีเมลทุกครั้งที่มีผลงานใหม่ส่งเข้ามา
3. ส่งลิงก์แบบฟอร์มในกลุ่ม LINE ผู้ปกครองและครู (หน้าภาพรวมมีปุ่มคัดลอกให้)
4. ส่งลิงก์หลังบ้านและรหัสเจ้าหน้าที่ให้เฉพาะครูผู้ตรวจและฝ่ายประชาสัมพันธ์

## การดูแลระบบ

| ต้องการ | ทำอย่างไร |
|---|---|
| เปลี่ยนรหัสเจ้าหน้าที่ | แก้ `STAFF_PASSCODE` ใน Apps Script แล้วรัน `setup` อีกครั้ง ไม่ต้อง Deploy ใหม่ |
| แก้โค้ด Apps Script | **Deploy › Manage deployments ›** กดไอคอนดินสอ **› Version: New version › Deploy** ลิงก์เดิมใช้ต่อได้ ไม่ต้องแก้ `config.js` |
| ดู/แก้ข้อมูลโดยตรง | เปิดชีต "ข้อมูลผลงานนักเรียน" ใน Drive ได้เลย ห้ามแก้คอลัมน์ "ข้อมูลนักเรียน (ระบบใช้ ห้ามแก้)" และ "รหัสอ้างอิง" |
| สำรองข้อมูล | ชีตและรูปอยู่ในโฟลเดอร์ "ระบบแจ้งผลงานนักเรียน" ใน Drive ทำสำเนาโฟลเดอร์ได้ตามปกติ |
| ลบรูปหรือผลงานผิดพลาด | รูปที่ลบจากหลังบ้านจะอยู่ในถังขยะของ Drive 30 วัน กู้คืนได้ |

## ข้อควรรู้

- **บัญชี Google Workspace for Education:** บางโรงเรียนไม่มีตัวเลือก *Who has access: Anyone* เพราะผู้ดูแลระบบปิดไว้ ให้ทำอย่างใดอย่างหนึ่ง
  - ขอให้ผู้ดูแล Google Workspace ของโรงเรียนอนุญาต
  - หรือติดตั้งด้วยบัญชี Gmail ที่โรงเรียนสร้างไว้สำหรับงานประชาสัมพันธ์
- **ความเป็นส่วนตัวของนักเรียน (PDPA):**
  - รูปนักเรียนเก็บใน Drive แบบส่วนตัว ไม่มีลิงก์สาธารณะ หน้าหลังบ้านโหลดรูปผ่าน Apps Script เฉพาะคนที่มีรหัส
  - ถ้าผู้ปกครองไม่ติ๊กยินยอม ระบบจะไม่ใส่รูปนักเรียนในกราฟิก
- **อย่าใส่รหัสเจ้าหน้าที่ลงใน GitHub:** รหัสอยู่ใน Apps Script เท่านั้น ลิงก์ `API_URL` ใน `config.js` เปิดเผยได้ เพราะแบบฟอร์มต้องใช้ส่งข้อมูล
- **กันสแปม:** แบบฟอร์มมีช่องซ่อนดักบอต ถ้ามีข้อมูลขยะเข้ามา ลบได้จากหลังบ้าน หรือเปลี่ยนลิงก์โดยสร้าง Deployment ใหม่
- **โควตาของ Google:** อีเมลแจ้งเตือนส่งได้วันละประมาณ 100 ฉบับ (Gmail ทั่วไป) หรือ 1,500 ฉบับ (Workspace) ซึ่งเพียงพอสำหรับโรงเรียนทั่วไป
- **โพสต์ลงเพจและ LINE:** ระบบเตรียมภาพและข้อความให้ แต่ฝ่ายประชาสัมพันธ์ต้องโพสต์เอง ระบบโพสต์อัตโนมัติไม่ได้

## โครงสร้างไฟล์

```
index.html          แบบฟอร์มแจ้งผลงาน (สาธารณะ)
staff.html          หลังบ้านสำหรับครูและฝ่ายประชาสัมพันธ์
config.js           ใส่ลิงก์ Web app ของ Apps Script
assets/style.css    หน้าตาร่วมของทุกหน้า
assets/common.js    ค่าคงที่ (ระดับ ประเภท รางวัล) และการเชื่อมต่อระบบหลังบ้าน
assets/poster.js    วาดกราฟิกแสดงความยินดีและสร้างแคปชัน
assets/staff.js     การทำงานของหน้าหลังบ้าน
apps-script/Code.gs โค้ดระบบหลังบ้าน (วางใน script.google.com ไม่ได้ทำงานบน GitHub)
```

**ต้องการเพิ่มระดับ ประเภทผลงาน หรือชื่อรางวัล:** แก้ได้ที่ตัวแปร `LEVELS`, `CATS`, `AWARDS` ในไฟล์ `assets/common.js`
